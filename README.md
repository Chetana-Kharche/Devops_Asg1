## How to Run the Project

1. Clone the repository:

```bash
git clone https://github.com/Chetana-Kharche/Devops_Asg1.git
```

2. Open the required assignment folder.

3. For HTML assignments, open the `index.html` file in a web browser.

4. For Node.js projects:

```bash
npm install
npm start
```

5. For React projects:

```bash
cd frontend
npm install
npm start
```
